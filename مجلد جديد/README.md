# منظومة مصنع الكوت للأسمنت | Cement Plant ERP System

مشروع Next.js 14 كامل وجاهز لبناء وتطوير منظومة إدارة الحسابات، الأصول قيد التنفيذ (CWIP)، وتسوية العهد المزدوجة بالعملتين (LYD / USD) بأسلوب شبيه بأنظمة Odoo و NetSuite العالمية.

## 🚀 خطوات التشغيل على جهازك المحلي:

1. **تأكد من وجود Node.js:** قم بتثبيت Node.js (الإصدار 18 أو أحدث) على جهازك.
2. **فك ضغط الملف:** قم بفك ضغط ملف `cement_plant_erp_nextjs.zip`.
3. **افتح المجلد في واجهة الأوامر (Terminal / CMD):**
   ```bash
   cd cement_plant_erp_nextjs
   ```
4. **تثبيت الحزم والمكتبات:**
   ```bash
   npm install
   ```
5. **تشغيل المنظومة محلياً:**
   ```bash
   npm run dev
   ```
6. **معاينة المنظومة:** افتح المتصفح وانتقل إلى العنوان: `http://localhost:3000`

---

## 🤖 كيف تتعامل مع هذا المشروع ومع كلاود؟

1. **رفع المشروع إلى كلاود:** عند التعامل مع كلاود، يمكنك إرفاق الملفات المحددة (مثل `app/page.jsx` أو `prisma/schema.prisma`) وطلب تعديلها أو إضافة ميزات جديدة عليها.
2. **طلب الموديولات بالتتابع:** استخدم الأوامر الخمسة المخصصة المرفقة بالدليل لإضافة كل موديول (قواعد البيانات، المحاسبة المزدوجة، الواجهات، وتعدد الشركات SaaS).
